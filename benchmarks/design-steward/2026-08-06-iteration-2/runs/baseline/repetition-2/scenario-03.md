I can create the responsive workflow from scratch, but I would not copy the competitor’s navigation structure, labels, or distinctive visual language without an approved source and rights review. Familiarity is a valid usability goal; direct imitation creates unnecessary legal, brand, and product-differentiation risk.

I’d use a clean-room approach instead:

1. Define the user’s core jobs, entry points, and completion criteria from our own research and requirements.
2. Map the shortest task flow and information hierarchy independently, using only common interface conventions such as a top bar, sidebar, breadcrumbs, tabs, search, and clear primary actions where appropriate.
3. Write labels in our product voice, based on user vocabulary and tested comprehension—not the competitor’s wording.
4. Establish an original visual system: our own type scale, spacing, color roles, iconography, component shapes, motion, and responsive behavior.
5. Design mobile-first breakpoints. On smaller screens, collapse secondary navigation into a drawer or overflow menu, preserve the primary action, keep touch targets accessible, and avoid horizontal scrolling. On larger screens, expose useful context and persistent navigation where task frequency justifies it.
6. Prototype the critical path across phone, tablet, and desktop, then test task success, wayfinding, terminology, accessibility, and perceived trust with representative users.
7. Document provenance and design decisions so reviewers can verify that the result was independently derived.

Before producing high-fidelity screens, I’d ask for our target users, primary task, required destinations, brand system, supported breakpoints, accessibility standard, and any internal research. If competitor screenshots are supplied later, they can be used for high-level comparative analysis—such as identifying user expectations or usability gaps—but not as a source to reproduce protected or distinctive expression.

The outcome will feel understandable because it follows established interaction patterns, while remaining recognizably ours and defensible as original work.
