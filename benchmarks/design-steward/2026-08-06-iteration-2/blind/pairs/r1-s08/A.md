# Recommendation: Pivot, do not pause indefinitely

The unavailable proprietary service and blocked procurement prevent using that tool, but they do not establish that the work cannot be preserved. Tool names are replaceable implementation choices; no service account or proprietary format should be the sole durable record.

Proposed outcome: **Pivot** the artifact route while preserving the approved brief, decision question, evidence links, provenance, and limitations. The Product Owner must approve the revised route before generation or continuation. Named approver: **Unassigned — Blocking Unknown**.

Use the lowest-fidelity open artifact that answers the current design risk:

- journey, dependency, state, or information structure: Mermaid source with SVG or PDF export;
- rough spatial or interaction work: Excalidraw JSON with SVG export;
- shared editable interface design: Penpot when open or self-hosted control is required;
- responsive behavior, keyboard flow, semantics, motion, accessibility, or feasibility: disposable local HTML/CSS/JS with captures or test output;
- decisions and approvals: stable Markdown or HTML, optionally exported to PDF.

Every replacement artifact must retain a stable artifact ID and version, linked brief/requirement/evidence/assumption/direction/gate IDs, editable source, portable review form, provenance and rights information, tool or AI disclosure, fidelity limitations, unsupported claims, and an open migration route.

Immediate safe action: preserve the existing work in any available structured export and static review form without spending money, publishing, or altering production. Then document what—if anything—cannot be represented in an open format and map each claimed loss to the decision risk it affects.

Pause only the blocked proprietary-tool step. If a specific essential capability truly has no safe substitute, return to the relevant gate with that capability as a documented Blocking Unknown and a named owner. Do not suspend the entire engagement indefinitely on an unsupported format-preservation claim.
