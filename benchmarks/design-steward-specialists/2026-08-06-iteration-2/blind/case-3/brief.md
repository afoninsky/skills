# Case 3: Shared-garden maintenance request

**Charter:** A status-first civic record whose visual identity comes from visible provenance, correction, and recovery rather than decoration.

**Priority journey:** A resident categorizes a maintenance issue, gives an approximate text location and description, reviews a privacy notice, submits, receives a reference, follows status history, and requests a correction.

**Representative content:** Category; approximate location; description; optional photo presence; privacy disclosure; reference ID; current status; history entries where supplied; correction route; upload and submission failure states.

## Fixed constraints

- Responsive from 320 to 1440 CSS pixels
- System font only and no map
- WCAG 2.2 AA intent, high-contrast-mode resilience, visible focus, and no color-only status
- No external assets or packages
- Do not invent actors, timestamps, retention, correction permissions, or submission persistence

## Open axes

- palette
- hierarchy
- layout
- restrained public-fixture illustration outside the task path
