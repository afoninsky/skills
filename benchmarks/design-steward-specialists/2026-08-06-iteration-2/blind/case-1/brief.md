# Case 1: Community tool-loan pickup board

**Charter:** A calm, object-first pickup board that makes limited appointment windows comparable without manufacturing urgency.

**Priority journey:** A resident compares available pickup windows, checks tool and deposit requirements, reserves one window, and recovers if that window becomes unavailable during confirmation.

**Representative content:** Tool name and category; pickup date and 30-minute window; depot; deposit; required identification; accessibility note; remaining reservations; reservation state.

## Fixed constraints

- Responsive from 320 to 1440 CSS pixels
- System font only
- No photography, countdowns, scarcity copy, gradients, or external icon packages
- WCAG 2.2 AA intent, visible focus, reduced-motion support, and no color-only meaning
- Do not promise inventory locking, persistence, or availability behavior that the brief does not confirm

## Open axes

- palette
- hierarchy
- layout
- native or CSS-drawn icon treatment
