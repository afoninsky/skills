# Direction capability preflight

Use this only when a selected direction method needs a capability that may not be available. Verify the means to create and inspect the visual evidence; do not make tool setup a prerequisite to design judgment when an established equivalent already works.

## Minimum capabilities

Depending on the request, direction work may need:

- an isolated writable medium for candidates;
- a real render or export path for visual comparison;
- current web access for unfamiliar audience, platform, font, asset, or domain research;
- an editable design source only when later collaboration requires it;
- representative participants only for a claimed preference or comprehension result;
- hosting or device distribution only when the intended reviewers cannot inspect local evidence.

Penpot, browser code, native previews, existing design tools, and supplied annotated references are possible adapters. None is canonical by brand. Image generation is optional and does not replace editable interface structure.

## Check proportionally

1. Define the comparison or decision and what evidence can resolve it.
2. Inspect existing project design tools, fonts, assets, preview paths, and conventions.
3. Prove the selected renderer or exporter with one disposable representative frame.
4. Verify external tools read-only before requesting write access.
5. Continue with an equivalent established path when it preserves the needed fidelity and collaboration. Ask only when the fallback materially changes the deliverable.

When a formal suite toolchain record already exists, use its statuses: `available`, `missing-blocking`, `missing-degradable`, `unknown`, and `not-applicable`. Do not create or refresh that record for routine work unless project protocol requires it.

## Missing evidence

- Without an actual render or supplied visual evidence, describe a thesis but do not claim visual comparison quality.
- Without matched content, state, and target conditions, limit comparative conclusions accordingly.
- Without representative participants, do not call a direction user-preferred or validated.
- Without durable editable source where the request requires it, disclose the collaboration limitation.

If setup is genuinely needed, use current official documentation, explain the exact change and rollback, obtain authorization for installs/accounts/publication, and verify with a minimal real output.
